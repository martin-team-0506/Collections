import random

載入隨機工具，讓程式能模擬擲骰。

import random
網頁對應：以JavaScript產生隨機點數。

random.randint(1, 6)

從1到6隨機產生一個整數。

d1 = random.randint(1, 6)
網頁對應：每回合產生六顆骰子。

自訂函式

把擲骰、計算與牌型判斷包成可重複使用的功能。

def get_dice_result():
    # 擲骰並判斷牌型
網頁對應：分析每一組三骰結果。

sorted()

由小到大排序，方便判斷連號與相同點數。

d_sorted = sorted([d1, d2, d3])
網頁對應：顯示排序後點數並辨認牌型。

串列與索引

用串列保存骰面圖案，再依點數取出。

dice_faces = ["", "⚀", "⚁",
              "⚂", "⚃", "⚄", "⚅"]
網頁對應：依點數排列骰面圓點。

多個回傳值

函式一次帶回骰子、總點數、等級與名稱。

return d1, d2, d3, total, rank, name
網頁對應：一次更新完整牌型資料。

多變數接收

用多個變數接住函式回傳的不同資料。

p1, p2, p3, p_total,
p_rank, p_name = get_dice_result()
網頁對應：玩家與電腦各自保存結果。

if / elif / else

依骰子組合判斷牌型，再依等級與總點數判斷勝負。

if rank_player > rank_computer:
    print("玩家獲勝")
網頁對應：產生回合結果與金幣結算。

while True

下注錯誤時持續要求重新輸入。

while True:
    bet_str = input("下注金額：")
網頁對應：驗證通過前不能擲骰。

isdigit()

檢查文字內容是否全部都是數字，先擋下英文字、小數與負號。

if not bet_str.isdigit():
    continue
網頁對應：不合法的下注不會啟動骰子。

int()

把通過檢查的數字文字轉換成可計算的整數。

bet = int(bet_str)
網頁對應：將下注欄位內容轉成金幣數量。

break與continue

continue重新檢查；break離開防呆迴圈。

if not bet_str.isdigit():
    continue
break
網頁對應：錯誤時提示，正確時開始回合。

and與or

組合多個遊戲條件。

while player_wins < 3 and
      computer_wins < 3 and coins > 0:
網頁對應：任一結束條件達成就停止。

+=與-=

用簡短寫法增加或減少勝場與金幣。

coins += bet
coins -= bet
網頁對應：依照勝負完成金幣結算。

f-string

把變數內容直接放進顯示文字中。

print(f"你目前擁有 {coins} 枚金幣")
網頁對應：產生即時比分與戰鬥紀錄。

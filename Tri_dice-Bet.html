v2.1：對子的比較順序

當雙方都是兩顆相同時，先比較相同兩骰的點數，相同才比剩下的一顆。Python可以用一組兩個值依序比較。

def pair_key(dice):
    a, b, c = sorted(dice)
    single = c if a == b else a
    return b, single

# 只在雙方都是對子時使用
player = pair_key([6, 2, 6])  # (6, 2)
computer = pair_key([5, 5, 6])  # (5, 6)
print(player > computer)  # True
網頁對應：6點對子勝過5點對子，總點數仍會顯示，這時不作為決勝依據。

🐍 Python學習小教室

import random

載入Python的隨機工具，讓程式能模擬擲骰子。

import random
網頁對應：使用JavaScript產生隨機點數。

random.randint(1, 6)

從1到6中隨機產生一個整數，就像擲一顆六面骰。

dice = random.randint(1, 6)
網頁對應：每回合隨機產生四顆骰子。

串列與索引

把骰子圖案排成串列，再用點數找到對應位置。

dice_faces = ["", "⚀", "⚁",
              "⚂", "⚃", "⚄", "⚅"]
print(dice_faces[3])
網頁對應：依點數排列骰面上的圓點。

變數

使用變數保存骰子點數、總點數、勝場與回合。

player_total = player_dice1 + player_dice2
網頁對應：即時更新總點數與計分板。

布林值

比較兩顆骰子是否相同，結果只有True或False。

player_is_double = (
    player_dice1 == player_dice2
)
網頁對應：判斷是否出現「豹子」。

while迴圈

雙方都還沒取得3勝時，比賽就持續進行。

while player_wins < 3 and computer_wins < 3:
網頁對應：遊戲結束前可以不斷擲骰。

if / elif / else

先判斷豹子，再比較點數，選出正確的回合結果。

if player_is_double:
    print("豹子！")
elif player_total > computer_total:
    print("玩家獲勝")
網頁對應：決定勝負訊息與得分者。

+=與 f-string

+=讓數值增加；f-string把變數放進顯示文字。

player_wins += 1
print(f"總點數是 {player_total}")
網頁對應：增加分數並產生戰鬥紀錄。

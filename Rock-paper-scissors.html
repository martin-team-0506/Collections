🐍 Python學習小教室

input()：接收輸入

像遊戲開始時詢問名字，把玩家輸入的文字交給程式。

name = input("請輸入名字：")

變數：程式的收納盒

幫名字、裝備、分數貼上標籤，之後就能拿來使用。

player_wins = 0
equipment = "洞察眼鏡"

random.choice()：隨機選擇

從三種拳中隨機挑一種，讓電腦每回合都有不同選擇。

computer = random.choice(options)

while：重複挑戰

只要雙方都還沒拿到5勝，比賽就會繼續進行。

while player_wins < 5 and computer_wins < 5:
    print("繼續挑戰！")

if / elif / else：判斷勝負

依照雙方出的拳，讓程式選擇該執行哪一種結果。

if player == computer:
    print("平手")
elif player == "石頭":
    print("繼續判斷")

continue：重新開始

輸入錯誤時，跳過這一次，直接回到迴圈開頭再試一次。

if player not in options:
    continue

random.random()：30%技能機率

產生0到小於1的隨機數；小於0.3代表本次洞察成功。每回合只抽一次。

if equipment == "洞察眼鏡" and round_num <= 3:
    if random.random() < 0.3:
        print(computer_choice)

連敗變數與技能條件

敗場讓連敗加1；一般平手或勝利歸零。手套抵銷的首回合敗場仍增加連敗。

if equipment == "狂暴之錘" and consecutive_losses >= 2:
    player_wins += 1
    consecutive_losses = 0

while True與break：再玩一次

外層迴圈啟動新比賽；重新開始時要清空比分、回合與連敗。break可離開遊戲。

while True:
    # 建立角色，重新計分並進行比賽
    play_again = input("再玩一次？y / n：")
    if play_again.lower() != "y":
        break

f-string：把變數放進文字

在引號前加上f，再用大括號放入變數，訊息就能跟著變化。

print(f"歡迎冒險者 {name}！")

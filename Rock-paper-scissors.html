🐍 Python學習小教室

input()：接收輸入

像遊戲開始時詢問名字，把玩家輸入的文字交給程式。

name = input("請輸入名字：")

變數：程式的收納盒

幫名字、裝備、分數貼上標籤，之後就能拿來使用。

player_wins = 0
equipment = "魔法魔杖"

random.choice()：隨機選擇

從三種拳中隨機挑一種，讓電腦每回合都有不同選擇。

computer = random.choice(options)

while：重複挑戰

只要雙方都還沒拿到3勝，比賽就會繼續進行。

while player_wins < 3:
    print("繼續挑戰！")

if / elif / else：判斷勝負

依照雙方出的拳，讓程式選擇該執行哪一種結果。

if player == computer:
    print("平手")
elif player == "石頭":
    print("繼續判斷")

continue：重新開始

輸入錯誤時，跳過這一次，直接回到迴圈開頭再試一次。

if player not in options:
    continue

f-string：把變數放進文字

在引號前加上f，再用大括號放入變數，訊息就能跟著變化。

print(f"歡迎冒險者 {name}！")
用Python邏輯打造的互動猜拳遊戲｜勇敢挑戰，從錯誤中學習！
